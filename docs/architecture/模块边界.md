# 模块边界

## 原则

1. **目录即模块**：一目录一清晰职责  
2. **边端插件化**：主机只依赖 ABI；相机/惯导在 `edge_agent/plugins/`  
3. **控制面微服务**：服务之间不直接 import 内部代码，只走 HTTP/MQ  
4. **协议先行**：`platform/protocols/` 为契约源
