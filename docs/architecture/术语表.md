# 术语表（中英对照）

本表服务学习与复刻；实现细节以代码与 Sxx 为准。

| 术语 | 英文/缩写 | 在本仓的含义 |
|------|-----------|--------------|
| 边端 | Edge | 靠近相机的采集主机，`edge_agent` |
| 控制面 | Control plane | 设备/会话/告警等微服务 + BFF |
| 插件 ABI | Plugin ABI | `CameraPluginAbi` 的 C 导出符号约定 |
| 环缓 | Ring buffer | 定长环形缓冲，满则丢旧保新 |
| 预览 | Preview | `latest.jpg` + `/preview` |
| 成片/点播 | VOD | `preview.mp4` + `/vod` |
| 回放索引 | Playback index | `/api/playback/{session}` 元数据 |
| 心跳 | Heartbeat | 边端定期上报在线 |
| 双模/三模鉴权 | Auth modes | API Key / Device Token / JWT |
| RBAC | Role-based access control | `require_roles(...)` |
| 审计 | Audit | `command_audits` 表 |
| BFF | Backend for Frontend | `control_bff` 聚合 |
| 发件箱 | Outbox | MQ 失败写本地 jsonl / 表 |
| 死信队列 | DLQ | 消费失败转入的队列 |
| 幂等 | Idempotency | 同 event_id 只处理一次 |
| 追踪 | Tracing | `X-Trace-Id` / `traceparent` / span |
| 迁移 | Migration | `001_init_schema.sql` 等 |
| ORM | Object-Relational Mapping | SQLAlchemy models |
| 租户 | Tenant | `tenants` 多客户隔离 |
| 软编/硬编 | Soft/Hard encode | ffmpeg CPU vs MPP |
| MPP | Media Process Platform | 瑞芯微硬编解码栈 |
| V4L2 | Video4Linux2 | Linux 视频设备接口 |
| Compose | Docker Compose | `platform/infra/docker-compose.yml` |
| E2E | End-to-end | `scripts/e2e_test.sh` |
