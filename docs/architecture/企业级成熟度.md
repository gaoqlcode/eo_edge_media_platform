# 企业级成熟度评估（诚实版）

> 更新日期：随仓库演进更新。目标：可上线园区/工业边缘视频平台水平。

## 总评

| 维度 | 现状 | 目标 |
|------|------|------|
| 架构拆分 | 已微服务化（设备/会话/索引/告警/BFF/边端/网关/worker） | 保持 |
| 数据层 | PG 迁移 + ORM；本机 micromamba PG 可用 | Compose 内 PG 一键起 |
| 中间件 | Redis/RabbitMQ 已跑；心跳进缓存与 MQ；**DLQ worker 已落地** | 幂等消费、重试策略可配置 |
| 安全 | API Key + **BFF JWT 登录/me** | 全服务 JWT/RBAC、审计强制 |
| 可观测 | 结构化日志 + `/metrics` | 全链路 tracing |
| 媒体能力 | **JPEG 预览管线**（JpegWriter → latest.jpg → gateway :9101） | H.264 流 + 回放索引 |
| 工程化 | e2e（含 preview/JWT）+ CI | 多环境配置、灰度 |
| 文档 | S00–S17 完成；**S18 RK3588 文档已开** | 板端实机勾选 |

**一句话**：联调级企业骨架可用（鉴权起步、JPEG 预览、DLQ）；上生产前还需全链路 JWT/RBAC、真编码流、tracing 与运维手册。
