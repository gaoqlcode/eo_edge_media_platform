# 企业级成熟度评估（诚实版）

> 更新日期：随仓库演进更新。目标：可上线园区/工业边缘视频平台水平。

## 总评

| 维度 | 现状 | 目标 |
|------|------|------|
| 架构拆分 | 已微服务化（设备/会话/索引/告警/BFF/边端/网关） | 保持 |
| 数据层 | PG 迁移 + ORM；本机 micromamba PG 可用 | Compose 内 PG 一键起 |
| 中间件 | Redis/RabbitMQ 容器已跑；心跳进缓存与 MQ | 死信队列、重试、幂等 |
| 安全 | **偏弱**：仅开始补 API Key | JWT/RBAC、审计强制 |
| 可观测 | 偏弱；补结构化日志与 /metrics | 全链路 tracing |
| 媒体能力 | 模拟帧+元数据落盘，**非真编码预览** | H.264/JPEG 预览与回放 |
| 工程化 | e2e 脚本有；补 Dockerfile/CI/网关 | 多环境配置、灰度 |
| 文档 | 复刻索引齐全；学习章深浅不一 | 按 Sxx 继续加厚 |

**一句话**：学习/联调级企业骨架已完成；上生产前还需鉴权加固、真媒体管线、完整观测与运维手册。
