## 2. 日常启动

```bash
cd /home/gaoql/eo_edge_media_platform
bash scripts/start_infra_local.sh
bash scripts/start_python_services.sh
# C++
cmake -S . -B build && cmake --build build -j$(nproc)
EMP_DATA_ROOT=$PWD/data/sessions EMP_PREVIEW_ROOT=$PWD/data/preview \
  ./build/bin/edge_agent ./build/lib/libemp_cam_Virtual.so
EMP_PREVIEW_ROOT=$PWD/data/preview EMP_SESSION_ROOT=$PWD/data/sessions \
  ./build/bin/media_gateway
```

一键验收：`bash scripts/e2e_test.sh`

停止 Python：`bash scripts/stop_python_services.sh`

## 3. 关键变量清单

| 变量 | 含义 | 示例 |
|------|------|------|
| DATABASE_URL | SQLAlchemy URL | `postgresql+psycopg2://emp@127.0.0.1:55432/emp_platform` |
| REDIS_URL | Redis | `redis://127.0.0.1:56379/0` |
| RABBITMQ_URL | AMQP | `amqp://emp:emp_dev_pass@127.0.0.1:5672/` |
| EMP_API_KEY | 服务间 Key | `emp-dev-key` |
| EMP_DEVICE_TOKEN | 边端凭证 | 默认回退 API Key |
| EMP_JWT_SECRET | JWT 密钥 | 生产必须更换 |
| EMP_PREVIEW_ROOT | latest.jpg 根 | `data/preview` |
| EMP_SESSION_ROOT | 会话成片根（gateway） | `data/sessions` |
| EMP_DATA_ROOT | edge_agent 会话根 | `data/sessions` |
| EMP_ENCODE_H264 | 边端结束是否软编 | `1` 开启（默认开启若未设 0） |

## 4. PostgreSQL 备份 / 恢复

```bash
# Local
pg_dump -h 127.0.0.1 -p 55432 -U emp -d emp_platform -Fc -f /tmp/emp_pg.dump
# 恢复到空库
createdb -h 127.0.0.1 -p 55432 -U emp emp_restore || true
pg_restore -h 127.0.0.1 -p 55432 -U emp -d emp_restore /tmp/emp_pg.dump
```

Compose：

```bash
sudo docker exec emp_postgres pg_dump -U emp emp_platform -Fc > /tmp/emp_compose.dump
```

## 5. 指标与追踪

- 每服务：`GET /metrics`（Prometheus 文本）  
  - `emp_http_requests_total` / `emp_http_errors_total`  
  - `emp_auth_fail_total`（401）/ `emp_authz_fail_total`（403）  
- 响应头：`X-Trace-Id`、`X-Span-Id`、`traceparent`（W3C）  
- 日志字段含 `trace=` `span=`  

完整 OTEL Exporter 为后续增强；当前约定已兼容替换。

## 6. 排障速查

| 现象 | 排查 |
|------|------|
| 服务 health 失败 | `.run/<service>.log`；`DATABASE_URL` 是否指向存活 PG |
| 401 满天飞 | 是否带 `X-API-Key` / Device Token / Bearer |
| 403 | RBAC：创建设备需 admin/service |
| 预览 404 | edge_agent 是否写出 `EMP_PREVIEW_ROOT/<device>/latest.jpg`；gateway 同根路径 |
| `/vod` 404 | 是否生成 `data/sessions/<sess>/cam0/preview.mp4`；`EMP_SESSION_ROOT` |
| MQ 无消费 | `docker ps` rabbit；worker 进程；看 `/tmp/emp_outbox.jsonl` |
| e2e 幂等失败 | Redis 残留键；测试已用随机 event_id |
