# 80 · 实战导读（精读 e2e）

## 1. 学习目标

独立读懂并跑通 `scripts/e2e_test.sh`，能对照日志定位失败步骤。

## 2. 脚本结构（按执行顺序）

| 段 | 做什么 | 失败时看 |
|----|--------|----------|
| infra | `start_infra_local.sh` PG/Redis | postgres.log / 端口占用 |
| unit | `pytest tests/unit` | 鉴权/幂等/trace 断言 |
| deps | 确保 fastapi/jwt… | pip / 哪个 python |
| build | cmake + ctest | jpeg/pthread 链接 |
| start py | 五服务 health | `.run/*.log` |
| auth- | 无 Key 建设备 → 401 | auth.py |
| API | 设备/会话/资产/告警/审计 SQL | DATABASE_URL |
| JWT | login + Bearer 写告警 | jwt_auth / 角色 |
| idem | 随机 event_id 幂等 | Redis |
| edge | 采帧 JPEG + 自动 H.264 | ffmpeg、EMP_ROOT |
| gw | preview + **vod** + playback | EMP_*_ROOT |
| metrics/trace | auth_fail、traceparent | 中间件 |

完整成功句：`E2E PASSED (enterprise checks)`。
