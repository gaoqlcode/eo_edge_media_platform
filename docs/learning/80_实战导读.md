## 2. e2e 在测什么

1. 起 infra（PG/Redis）  
2. pytest 单元（鉴权/幂等/metrics）  
3. CMake 编译 C++  
4. 起五服务 health  
5. 无密钥写设备 → 401  
6. 带 Key 建设备/会话/资产/告警；playback；JWT 双模  
7. worker 幂等  
8. edge_agent 出 JPEG；可选 ffmpeg；gateway preview
