# 20 · 数据结构与环形缓冲

## 概念
音视频管线里，采集线程快、编码/网络慢时，需要**有界缓冲**。环形缓冲（Ring Buffer）用固定数组 + 头尾指针，避免频繁分配。

## 本项目位置
- 实现：`platform/libs/emp_common/include/emp/RingBuffer.h`
- 练习：`labs/data_structures/ringbuffer_demo.cpp`
- 使用：`edge_agent` 采帧后 `push_overwrite`（满则丢旧保新）

## 动手
```bash
cmake -S . -B build && cmake --build build --target lab_ringbuffer
./build/bin/lab_ringbuffer
```
