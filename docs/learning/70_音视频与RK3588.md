# 70 · 音视频与 RK3588

## 1. 学习目标

- 走通 JPEG 预览链路与可选 H.264 成片  
- 理解插件相机（Virtual / V4L2_Stub → 真 V4L2）  
- 知道 RK3588 移植清单（S18）哪些能在 WSL 先做  

对应 S14、S15、S18。

---

## 2. 概念详解

### 2.1 本仓媒体路径（教学级）

```text
插件 grab 元数据
  → 生成测试 RGB
  → JpegWriter → 会话目录 N.jpg + preview/latest.jpg
  → media_gateway GET /preview?device=...
  → （可选）ffmpeg 把 N.jpg 编成 mp4
  → media_indexer 登记资产 / playback 索引
```

不是完整直播协议；是**可落地的企业预览 + 成片索引**骨架。

### 2.2 编码角色

| 组件 | 角色 |
|------|------|
| libjpeg | 软 JPEG |
| ffmpeg 脚本 | 软 H.264/MP4 |
| RK MPP（板端） | 硬编，替换软路径 |

### 2.3 V4L2

Linux 视频设备 `/dev/videoX`。Stub 插件占位；真插件读 mmap 缓冲。  
WSL 可能无真实摄像头——用 Virtual 插件。

### 2.4 RK3588 要点

见 [S18](../rebuild/S18_RK3588移植.md)：aarch64 编译、systemd、网络回中心、预览拉流。

## 5. 动手实验

```bash
cd /home/gaoql/eo_edge_media_platform
EMP_FRAMES=5 EMP_DEVICE_CODE=edge-demo \
  EMP_DATA_ROOT=$PWD/data/sessions EMP_PREVIEW_ROOT=$PWD/data/preview \
  ./build/bin/edge_agent ./build/lib/libemp_cam_Virtual.so
./build/bin/media_gateway &
curl -o /tmp/p.jpg "http://127.0.0.1:9101/preview?device=edge-demo"
file /tmp/p.jpg
```
