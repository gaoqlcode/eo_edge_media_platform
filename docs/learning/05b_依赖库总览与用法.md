## 2. C++ 与系统库

### 2.1 C++17 标准库（STL）

- **作用**：`string`、`vector`、`fstream`、`mutex`、`thread` 等，业务骨架不另引 Boost。  
- **安装**：随 `build-essential` / g++。  
- **本仓**：几乎所有 `.cpp`；环形缓冲模板在 `RingBuffer.h`。  
- **最小示例**：见 `labs/cpp_syntax/hello_types.cpp`。

### 2.2 libdl（`dlopen` / `dlsym`）

- **作用**：运行时加载 `.so` 插件，实现相机「可插拔」。  
- **安装**：glibc 自带；CMake `target_link_libraries(... dl)`。  
- **本仓**：`platform/libs/emp_common` → `PluginLoader`；`edge_agent` 加载 `libemp_cam_Virtual.so`。  
- **用法要点**：插件导出 C ABI（`extern "C"`），主机只认函数指针表，不依赖插件 C++ 类布局。

### 2.3 libjpeg

- **作用**：把 RGB 缓冲压成 JPEG 文件（预览 `latest.jpg`、会话逐帧）。  
- **安装**：`sudo apt install -y libjpeg-dev`。  
- **本仓**：`JpegWriter.h/.cpp`；CMake `emp_common` 链接 `jpeg`。  
- **最小用法**：

```cpp
#include "emp/JpegWriter.h"
// emp::write_jpeg_file(path, width, height, rgb_bytes, quality);
```

- **验收**：跑 edge_agent 后存在 `data/preview/<device>/latest.jpg`。

### 2.4 pthread / Threads

- **作用**：`media_gateway` 里 TCP/HTTP 分线程监听。  
- **安装**：系统库；CMake `find_package(Threads REQUIRED)` + `Threads::Threads`。  
- **本仓**：`platform/services/media_gateway/src/main.cpp`。

### 2.5 CMake

- **作用**：描述如何编静态库 `emp_common`、共享库插件、可执行文件。  
- **安装**：`sudo apt install -y cmake`（建议 ≥ 3.16）。  
- **本仓**：根 `CMakeLists.txt`。  
- **关键命令**：`cmake -S . -B build && cmake --build build -j$(nproc)`。

### 2.6 ffmpeg（命令行工具，非链接库）

- **作用**：把 `0.jpg,1.jpg,...` 软编成 H.264/MP4。  
- **安装**：`sudo apt install -y ffmpeg`。  
- **本仓**：`scripts/encode_session_h264.sh`。  
- **用法**：

```bash
bash scripts/encode_session_h264.sh data/sessions/<sess>/cam0 /tmp/out.mp4
```

## 3. Python 库（requirements.txt）

统一安装：

```bash
.tools/mamba_root/envs/emp/bin/python -m pip install -r requirements.txt
```

### 3.1 FastAPI

- **作用**：声明式 HTTP API（路由、依赖注入、自动 OpenAPI）。  
- **用法**：`app = FastAPI()` 或本仓工厂 `create_service_app("device_service")`。  
- **本仓**：`platform/services/*/app.py`、`emp_py/fastapi_app.py`。  
- **要点**：写接口用 `Depends(require_auth)` 挂鉴权。

### 3.2 Uvicorn

- **作用**：ASGI 服务器，真正监听端口。  
- **用法**：`python -m uvicorn app:app --host 127.0.0.1 --port 8101`。  
- **本仓**：`scripts/start_python_services.sh`。

### 3.3 SQLAlchemy

- **作用**：ORM：Python 类 ↔ 表行。  
- **用法**：`Session`、`query(Model)`、`commit()`。  
- **本仓**：`emp_py/db.py`、`emp_py/models.py`。  
- **要点**：学习阶段用 ORM；复杂报表可直接 SQL（迁移文件是真理来源）。

### 3.4 psycopg2-binary

- **作用**：PostgreSQL 驱动；URL 形如 `postgresql+psycopg2://user@host:port/db`。  
- **本仓**：`DATABASE_URL` 环境变量；e2e 默认 `...@127.0.0.1:55432/emp_platform`。

### 3.5 Pydantic（v1）

- **作用**：请求/响应数据校验与文档生成。  
- **用法**：`class DeviceCreate(BaseModel): ...`。  
- **本仓**：各服务 `*In` / `*Create` 模型。  
- **注意**：锁定 `<2`，API 与 v2 不兼容。

### 3.6 httpx

- **作用**：同步/异步 HTTP 客户端。  
- **本仓**：`control_bff` 聚合 device/session/alarm。  
- **示例**：`httpx.Client(timeout=2.0).get(url, headers={"X-API-Key": ...})`。

### 3.7 redis（Python 客户端）

- **作用**：连 Redis：缓存设备在线、幂等 SETNX。  
- **本仓**：`emp_py/redis_client.py`、`emp_py/idempotency.py`。  
- **要点**：连不上时降级内存字典，保证单机能测。

### 3.8 pika

- **作用**：RabbitMQ AMQP 客户端。  
- **本仓**：`emp_py/mq.py` 发布；`media_worker/worker.py` 消费 + DLX。  
- **要点**：`basic_ack` 成功；失败 `basic_nack(requeue=False)` 进死信。

### 3.9 PyJWT

- **作用**：JWT 签发/校验（HS256）。  
- **本仓**：`emp_py/jwt_auth.py`；BFF `/api/bff/login`、`/me`；写接口可 Bearer 双模。  
- **环境变量**：`EMP_JWT_SECRET`、`EMP_JWT_TTL`。

### 3.10 pytest

- **作用**：单元测试。  
- **本仓**：`tests/unit/`；e2e 脚本会先跑 pytest。

## 4. 中间件（运行时「大库」）

### 4.1 PostgreSQL

- **作用**：设备、会话、资产、告警、审计、outbox 的权威存储。  
- **下载**：micromamba PG 或镜像 `postgres:16`。  
- **本仓**：`platform/infra/migrations/001_init_schema.sql`；ORM `models.py`。  
- **连接**：`psql -h 127.0.0.1 -p 55432 -U emp -d emp_platform`。

### 4.2 Redis

- **作用**：短 TTL 缓存（如 `device:online:*`）、幂等键 `emp:idem:*`。  
- **下载**：本机 redis-server 或 `redis:7`。  
- **连接**：`REDIS_URL`（Local 默认 `redis://127.0.0.1:56379/0`）。

### 4.3 RabbitMQ

- **作用**：领域事件总线；交换机 `emp.events`；死信 `emp.events.dlx`。  
- **下载**：`rabbitmq:3-management`。  
- **连接**：`amqp://emp:emp_dev_pass@127.0.0.1:5672/`；管理台 `:15672`。  
- **本仓发布**：`publish_event("emp.device.heartbeat", {...})`。

### 4.4 Traefik / Prometheus

- **作用**：反向代理入口、指标抓取（Compose 可选栈）。  
- **本仓**：`platform/infra/docker-compose.yml`；服务自带 `/metrics`。
