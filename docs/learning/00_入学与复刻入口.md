# 00 · 入学：如何用本仓库学习与复刻

## 1. 你将建成什么

一套**可联调的边缘媒体平台骨架**：

- 边端 C++：插件采帧 → JPEG/预览 → 可选 H.264 → 心跳/会话  
- 控制面 Python：设备/会话/索引/告警/BFF  
- 中间件：PostgreSQL + Redis + RabbitMQ  
- 文档：复刻步骤 S00～S18 + 学习章（语法/结构/库/Git…）

诚实定位见 [企业级成熟度](../architecture/企业级成熟度.md)：学习/联调企业级，非开箱上生产。
