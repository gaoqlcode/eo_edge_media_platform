## 1. 目标

边端相机能力插件化：`edge_agent` 只认 ABI，Virtual / V4L2_Stub 可切换；未来真 V4L2 / 厂商 SDK 只需换 `.so`。

## 2. 前置

S05 `PluginLoader` + `CameraPluginAbi` 已有。

## 3. 操作

### 3.1 ABI 符号（`extern "C"`）

| 符号 | 含义 |
|------|------|
| `emp_create_camera` | 创建相机实例 |
| `emp_destroy_camera` | 销毁 |
| `emp_camera_plugin_id` | 插件名字符串 |
| `emp_camera_grab` | 抓一帧元数据 |

### 3.2 现有插件

| 插件 | 产物 | 说明 |
|------|------|------|
| Virtual | `build/lib/libemp_cam_Virtual.so` | 模拟帧，WSL 默认 |
| V4L2_Stub | `build/lib/libemp_cam_V4L2_Stub.so` | 占位，行为类似 Virtual，id 不同 |

```bash
cmake --build build -j$(nproc)
EMP_FRAMES=3 ./build/bin/edge_agent ./build/lib/libemp_cam_Virtual.so
EMP_FRAMES=3 ./build/bin/edge_agent ./build/lib/libemp_cam_V4L2_Stub.so
```

### 3.3 真 V4L2（板端待做）

1. 复制 Stub 为 `V4L2/` 目录  
2. `open("/dev/video0")` + `VIDIOC_QUERYCAP` / `REQBUFS` / `DQBUF`

4. 保持 ABI 不变，仅换 so 路径
