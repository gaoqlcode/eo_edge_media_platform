# S18 · RK3588 移植

> 状态：`[~] 进行中`（文档先落地，板端实机待你接板后勾选）

## 1. 目标

把 `edge_agent` + 相机插件跑到 RK3588（aarch64 Linux），控制面仍可在 x86 服务器。

## 2. 前置

- S14/S06 在 WSL 已通过 Virtual 插件  
- 板端：Debian/Ubuntu aarch64、网络可达 Redis/API  

## 3. 操作清单

1. **交叉或板端原生编译**
   ```bash
   # 板端原生示例
   cmake -S . -B build-rk -DCMAKE_BUILD_TYPE=Release
   cmake --build build-rk -j$(nproc)
   ```
2. **插件**：用 `libemp_cam_V4L2_Stub.so` 先跑通；再实现真 V4L2（`/dev/videoX`）替换 Stub。  
3. **硬编**：后续接 MPP/FFmpeg 硬编，替换 `JpegWriter` 软路径。  
4. **systemd**：参考 `legacy` 思路，将 `edge_agent` 作成服务，`Environment=EMP_DEVICE_CODE=...`。  
5. **预览**：板端写 `data/preview/<device>/latest.jpg`，地面站/网关拉 `http://<board>:9101/preview?device=...`。

## 4. 关键设计

边端与控制面解耦：板子只跑 edge_agent/gateway 热路径；PG/API 在机房。

## 5. 验收

- [ ] aarch64 下 Virtual 或 V4L2_Stub 可跑  
- [ ] 心跳进中心 device_service  
- [ ] 预览 JPEG 可被拉到  
- [ ] 断电重启后 systemd 自动拉起
