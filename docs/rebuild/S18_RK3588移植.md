# S18 · RK3588 移植

> 状态：`[~] 进行中`（文档先行；无板不勾选实机项）

## 1. 目标

在 RK3588（aarch64）跑通 `edge_agent` + 相机插件 +（可选）`media_gateway`；控制面仍在 x86/机房。

学习对照：[70_音视频与RK3588](../learning/70_音视频与RK3588.md)

## 2. 前置

| 项 | 说明 |
|----|------|
| WSL 已通 | S14 Virtual 插件、预览、心跳 |
| 板子系统 | Debian/Ubuntu aarch64，能上网或内网源 |
| 网络 | 板子能访问中心 `device_service` / Redis /（可选）MQ |
| 相机 | `/dev/videoX` 权限（`video` 组） |

## 3. 架构

```text
┌──────────── RK3588 ────────────┐     ┌────── 机房/WSL ──────┐
│ edge_agent + .so 插件          │────▶│ device/session/...   │
│ media_gateway :9101（可同机）  │◀────│ 客户端拉 preview/vod │
│ 本地 data/preview & sessions   │     │ PostgreSQL/Redis/MQ  │
└────────────────────────────────┘     └──────────────────────┘
```

原则：**热路径在板，状态与检索在中心**。

## 4. 操作清单（逐步）

### 4.1 工具链

板端原生（推荐先通）：

```bash
sudo apt update
sudo apt install -y build-essential cmake pkg-config libjpeg-dev git
# 可选：ffmpeg（软编）或 rockchip mpp 开发包（硬编）
```

交叉编译（可选）：在 x86 装 `aarch64-linux-gnu-g++`，CMake toolchain 文件指定编译器与 sysroot。

### 4.2 同步代码与编译

```bash
git clone git@github.com:gaoqlcode/eo_edge_media_platform.git
cd eo_edge_media_platform
cmake -S . -B build-rk -DCMAKE_BUILD_TYPE=Release
cmake --build build-rk -j$(nproc)
```

产物：`build-rk/bin/edge_agent`、`build-rk/lib/libemp_cam_*.so`

### 4.3 先跑 Stub / Virtual

```bash
export EMP_DEVICE_CODE=rk-edge-001
export EMP_DEVICE_URL=http://<中心IP>:8101/api/devices/heartbeat
export EMP_SESSION_URL=http://<中心IP>:8102/api/sessions
export EMP_API_KEY=emp-dev-key
export EMP_DEVICE_TOKEN=emp-dev-key
export EMP_DATA_ROOT=/var/lib/emp/sessions
export EMP_PREVIEW_ROOT=/var/lib/emp/preview
export EMP_ENCODE_H264=1   # 若无 ffmpeg 可 =0
mkdir -p "$EMP_DATA_ROOT" "$EMP_PREVIEW_ROOT"
./build-rk/bin/edge_agent ./build-rk/lib/libemp_cam_V4L2_Stub.so
```

中心应看到心跳与会话。

### 4.5 media_gateway 同机或旁路

```bash
export EMP_PREVIEW_ROOT=/var/lib/emp/preview
export EMP_SESSION_ROOT=/var/lib/emp/sessions

# 地面站：
curl -o p.jpg "http://<板IP>:9101/preview?device=rk-edge-001"
```

防火墙放行 9101（及若需要的 9100）。

### 4.6 systemd 保活

`/etc/systemd/system/emp-edge-agent.service` 示例：

```ini
[Unit]
Description=EMP edge_agent
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=emp
WorkingDirectory=/opt/emp
Environment=EMP_DEVICE_CODE=rk-edge-001
Environment=EMP_DEVICE_URL=http://10.0.0.10:8101/api/devices/heartbeat
Environment=EMP_SESSION_URL=http://10.0.0.10:8102/api/sessions
Environment=EMP_API_KEY=emp-dev-key
Environment=EMP_DATA_ROOT=/var/lib/emp/sessions
Environment=EMP_PREVIEW_ROOT=/var/lib/emp/preview
ExecStart=/opt/emp/bin/edge_agent /opt/emp/lib/libemp_cam_V4L2_Stub.so
Restart=on-failure
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now emp-edge-agent
sudo journalctl -u emp-edge-agent -f
```
