# S04 · 数据库迁移

> 状态：`[x] 已完成`

## 1. 目标

落地企业核心表：租户、设备、通道、会话、资产、告警、审计、发件箱；并有演示种子数据。

学习对照：[40_PostgreSQL](../learning/40_PostgreSQL.md)

## 2. 前置

S03 已能起 PostgreSQL（Local `:55432` 或 Compose `:5432`）。

## 3. 操作

### 3.1 文件

| 文件 | 作用 |
|------|------|
| `platform/infra/migrations/001_init_schema.sql` | 建扩展 pgcrypto、建表与索引 |
| `platform/infra/migrations/002_seed_demo.sql` | 默认租户与演示设备 |
| `platform/libs/emp_py/emp_py/models.py` | ORM 映射（教学简化） |

### 3.2 应用迁移

Local：

```bash
bash scripts/start_infra_local.sh
# 脚本内部会 psql 执行 001/002
psql -h 127.0.0.1 -p 55432 -U emp -d emp_platform -c '\dt'
```

Compose：首次启动 `emp_postgres` 时挂载到 `docker-entrypoint-initdb.d/`（仅空数据卷首次生效）。

### 3.3 表职责速查

| 表 | 职责 |
|----|------|
| tenants | 多租户隔离根 |
| devices | 边端档案与状态 |
| channels | 设备通道 |
| record_sessions | 一次采集会话 |
| media_assets | 会话下文件（jpeg_seq / h264_mp4） |
| alarm_events | 告警 |
| command_audits | 写操作审计 |
| outbox_events | 可靠发消息发件箱 |

## 4. 设计说明

- **SQL 为权威**：改表先改迁移；ORM 跟随。  
- 索引按查询习惯：设备状态、会话按设备时间、告警时间倒序、outbox 待发送。  
- 审计表已存在；业务通过 `emp_py.audit.write_audit` 写入。
