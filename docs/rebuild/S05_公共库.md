# S05 · 公共库 emp_common / emp_py

> 状态：`[x] 已完成`

## 1. 目标

抽出边端与控制面共用能力，避免每个服务复制粘贴。

学习对照：[05b_依赖库](../learning/05b_依赖库总览与用法.md)、[10_C++](../learning/10_C++语法入门.md)、[15_Python](../learning/15_Python语法与FastAPI.md)

## 2. 前置

S02 目录骨架；CMake / Python 环境可用。

## 3. 操作与目录

### 3.1 C++：`platform/libs/emp_common`

| 组件 | 路径 | 作用 |
|------|------|------|
| Logger | `Logger.h/.cpp` | 带模块名的日志 |
| Types | `Types.h` | 时间戳、设备码等别名 |
| RingBuffer | `RingBuffer.h` | 有界环缓 |
| PluginLoader | `PluginLoader.*` | dlopen 相机插件 |
| JpegWriter | `JpegWriter.*` | RGB→JPEG |
| CameraPluginAbi | `CameraPluginAbi.h` | 插件 C ABI |

编译进静态库 `emp_common`，链接 `dl` + `jpeg`。

### 3.2 Python：`platform/libs/emp_py`

| 模块 | 作用 |
|------|------|
| `fastapi_app` | 统一 /health /metrics 中间件追踪 |
| `auth` / `jwt_auth` | 三模鉴权 + RBAC |
| `audit` | command_audits |
| `db` / `models` | ORM |
| `mq` / `redis_client` / `idempotency` | 中间件 |
| `metrics` / `tracing` / `logging_setup` | 可观测 |

服务通过 `sys.path` 引入（见各 `app.py` 开头）。

## 4. 设计说明

- C++ 公共库只依赖系统库，不反向依赖业务服务。  
- Python 公共库可被所有微服务 import；业务表变更走迁移。  
- 插件 ABI 稳定：主机不依赖插件 C++ 类布局。
