## 3. 操作

确认目录：

```text
platform/infra/                 # compose、迁移、prometheus、traefik
platform/libs/emp_common/       # C++ 公共库
platform/libs/emp_py/           # Python 公共库
platform/services/
  edge_agent/ (+ plugins/)
  media_gateway/
  device_service/ session_service/ media_indexer/
  alarm_service/ control_bff/
  media_worker/
platform/clients/control_client/
platform/protocols/             # 契约占位
docs/rebuild|learning|architecture|ops|reference/
labs/cpp_syntax|data_structures|algorithms/
scripts/                        # start_* e2e encode
```

```bash
find platform docs labs scripts -maxdepth 2 -type d | head -60
```

## 4. 设计说明

| 边界 | 规则 |
|------|------|
| 插件 | 只实现 ABI；不依赖 edge_agent 内部类 |
| 微服务 | 不互相 import；HTTP/MQ |
| 公共库 | 被依赖，不依赖具体服务 |
| 文档 | 改代码同步 Sxx / 学习章 |

对照：`eo_pod_server`（边端）、`eo_pod_gcs`（地面站）——只读。
